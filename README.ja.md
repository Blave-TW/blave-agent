## ほかのトレーディングエージェントとの違い

### 過剰最適化を確かめ、実際の手数料で計算するバックテスト

過剰最適化とは、パラメータがたまたま過去のデータに合っているだけの状態のことです。

- Type A のバックテストでは、毎回デフォルトでモンテカルロ順列検定（MCPT、`lib/validation.py`）を実行し、p 値を記録します。データをシャッフルしても同じくらいの成績が出せたのではないか、を確かめるためです。
- パラメータ探索（`lib/param_scan.py`）が探すのは、いちばん成績のよい 1 マスではなく、どれを選んでも機能するパラメータの平坦域です。
- ローリング walk-forward（`lib/walk_forward.py`）でアウトオブサンプルの成績を測ります。
- 手数料は実際の市場に合わせるべきです。手数料 0 は `lib/quality_check.py` が警告しますが、変更を強制はしません。
- 1 つのアイデアにつき、バックテストはデフォルトで 1 回です。結果が悪ければそのまま報告し、数字がよく見えるまでこっそりパラメータを調整し直すことはしません（[`AGENTS.md`](AGENTS.md) の *Iteration Brakes* を参照）。

### 実運用で動いているのがバックテストしたコードかがわかる

バックテストのたびに、戦略のバージョンが固定されます。実運用で動いているコードがそのバージョンと一致しなくなると、その戦略にはフラグが付き、Web のワークスペースには「稼働中」ではなく「稼働中 · ファイル変更あり」と表示されます。フラグが付いても戦略の実行は止まりません。対象はバックテストを行う戦略タイプ（Type A と C）で、かつバージョンが記録された戦略だけです。

### 注文ループに LLM はいない

エージェントはリサーチとコードの記述を担当します。スケジュール実行されるのは決定的なコードで、`manager/reconciler.py` が口座を目標ポジションに近づけます。キルスイッチ（`state/HALT`）は注文ライブラリの層で新規のエクスポージャーをブロックし、決済とストップは通常どおり通します。

### ニュースを読んでから書くレポート

朝のブリーフィング、引け後のレポート、個別銘柄レポート、リサーチレポートを頼むと、エージェントは書く前にニュースを読みます——少なくとも 3 つの異なるサイトです。チャートはすべて実際のデータ系列から描き、モデルの記憶からは描きません。各レポートは、要約と「この読みが間違っていたとわかる条件」1 つで締めくくります。清算マップは、実際に清算された分とモデルによる推定を 2 つのレイヤーに分けて描き、それぞれにそう明記します。

### 見ていられるブラウザ

エージェントが Web を読むときは、アプリ内蔵のブラウザを使います。読んでいるページはあなたの画面に表示され、隠れたプロセスの中ではありません。取引所のアカウントページとプライベートネットワークのアドレスはブロックされます。この回にまだ訪れていないサイトの、長いパラメータを含む URL は、開く前にいったん止まってあなたに確認します。

## クイックスタート（ソースから）

必要なもの：

- macOS 13 以降。パッケージ版はユニバーサルビルドで、Apple Silicon と Intel のどちらも 1 つのダウンロードで動きます。
- または Windows 10、11 の x64（Electron 44 が対応するバージョン。ARM は未テスト）。Windows インストーラーにはまだコード署名がないため、初回インストール時に Windows が警告を表示します。説明文の下にあるリンクをクリックし、続けて画面の下に増えたボタンをクリックしてください。
- Node.js 22.12 以降と npm（`shell/package.json` › `engines`）
- `PATH` 上の `python3`（Windows では `python`）。パッケージ版は Python 3.12 を同梱しています。ソースから実行する場合は、システムの Python で venv を作成します。
- インストールしてサインイン済みの Claude Code または Codex、あるいは Blave アカウント

```
git clone https://github.com/Blave-TW/blave-agent.git
cd blave-agent/shell
npm install
npm start
```

Windows では PowerShell で実行します（PowerShell の実行ポリシーで `npm` スクリプトがブロックされても、`npm.cmd` なら動きます）：

```powershell
git clone https://github.com/Blave-TW/blave-agent.git
cd blave-agent\shell
npm.cmd install
npm.cmd start
```

初回起動時に、エージェントを動かす AI を選びます：

- **自分の Claude Code または Codex。** Blave アカウントは不要で、Blave は AI の料金を一切請求しません。アプリは CLI を起動するだけで、Claude Code や Codex の認証情報は CLI 側に残ります。
- **Blave AI。** Blave アカウントでサインインします。従量課金です。

あとはアイデアを話すだけです。たとえば：

- 「BTCUSDT の 4 時間足でバックテストして。20 期間 SMA が 60 期間 SMA を上抜けたらロング、下に戻ったらノーポジション。手数料は片道 0.05%。」
- 「BTC、ETH、SOL を均等ウェイトで組み、毎週リバランスするポートフォリオを作ってバックテストして。」
- 「その戦略の 2 つの SMA の長さを両方スキャンして、平坦域がどこにあるか見せて。」

エージェントはコードを書く前に、すべてのアイデアを 3 つのタイプのどれかに分類します：

| タイプ | 内容 | バックテスト |
|---|---|---|
| A | 固定の 1 銘柄・固定の時間足で、ポジションは 1 つ（ロング／ショート／ノーポジション） | 必須 |
| C | ポートフォリオ：N 銘柄と、合計が 1 以下のウェイトベクトル。スケジュールでリバランス | 必須 |
| B | それ以外すべて：スクリーナー、グリッド、アービトラージ、アラート、単発の執行 | なし |

インターフェースはシステムの言語に従います（英語または繁体字中国語）。上書きするには：`BLAVE_LANG=en npm start`（PowerShell：`$env:BLAVE_LANG="en"; npm.cmd start`）。

## 安全性と限界

- **取引所のキーの保存場所は、使う環境によって異なります。** デスクトップ版：あなたのコンピューター上のワークスペースの `.env`（macOS は `~/Blave/workspace/.env`、Windows は `%USERPROFILE%\Blave\workspace\.env`）。クラウドサーバー：あなた専用のサーバー上のワークスペースの `.env`。Web ページで取引所を連携した場合：キーは Blave が暗号化して保存します。エージェントはワークスペースの `.env` を読めますが、ルールでキーの値を表示することは禁じられています（`references/exchange-connect.md`）。キーには読み取り＋取引権限だけを付与し、出金権限は決して付与しないでください。出金権限のあるキーは接続時に拒否されます（Binance、OKX、BingX、Bybit。デスクトップ版、クラウドサーバー、Web ページのいずれでも同じです）。Gate.io はこの権限の情報をまったく返さないため、こちらはご自身で確認してください。
- 投入金額の設定と取引の再開は、あなた自身が行います——デスクトップ版はアプリの「自動売買」ページ、クラウドサーバーは Web のワークスペースで。頼まれても、エージェントは代わりに行いません。エージェントがいつでも自分の判断で行ってよいのは、キルスイッチを作動させることだけです。
- デスクトップ版では、Blave が起動している間だけ注文が出ます。終了して開き直したあとは、「取引を開始」を押すまで取引は一時停止したままです。
- エージェントは確かめてから報告します。ファイルを編集したら読み直し、注文を出したら取引所に照会してから「発注した」と伝えます。すべての注文試行は `state/audit.jsonl` に記録されます。
- バックテストが示すのは過去です。将来の結果を予測も保証もしません。MCPT は成績が統計的に有意かどうかを、パラメータ探索は過剰最適化していないかを確かめます。どちらもバックテストに騙される可能性を下げるだけで、なくすことはできません。
- ここにあるものはいずれも投資助言ではありません。取引では損失が出ることがあり、全額を失うこともあります。

## コード署名ポリシー

Windows 版にはまだコード署名がありません。[SignPath Foundation](https://signpath.org) のオープンソースプログラムに申請中で、承認されるまで Windows インストーラーは未署名です。承認後は、Windows のコード署名を [SignPath.io](https://signpath.io) が無償で提供し、証明書は SignPath Foundation が発行します。リリースは、このリポジトリの公開 GitHub Actions ワークフローがタグ付きのコミットからビルドし、署名リクエストはそのつどリポジトリのオーナーが承認します。役割：作成者とレビュアー——書き込み権限を持つメンテナー。承認者——リポジトリのオーナー。このプログラムは、[プライバシーポリシー](https://blave.org/disclaimer/ja/privacy_policy)に記載されている場合を除き、第三者に情報を一切提供しません。macOS 版は Blave 自身の Apple の署名 ID で署名・公証されています。
